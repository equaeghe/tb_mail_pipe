Thunderbird Mail Pipe

Define one or more "actions". Each action pipes the selected message(s) through an external script (via the native messaging host tb_mail_pipe) and imports the script's stdout as a new message. Every action automatically appears in the message-list context menu; you can additionally bind it to a keyboard shortcut slot below and assign an actual key combination in Thunderbird's Add-on Manager → gear icon → "Manage Extension Shortcuts".

The native host only allows scripts that are listed in its allow-list file (~/.config/tb-mail-pipe/allowed-scripts.json by default). Add each script's absolute path there before using it here. See the project README for details.
